# 한글날 자음 뽑기

**https://lovleap-prog.github.io/hangul-booth/**

한글날 부스에서 쓰는 자음 뽑기입니다. 쌍자음을 뺀 자음 14개
(ㄱㄴㄷㄹㅁㅂㅅㅇㅈㅊㅋㅌㅍㅎ)에서 두 개를 뽑고, 그 자음이 들어간
낱말을 말하거나 그리는 미션에 씁니다.

## 할 수 있는 것

- **2개 한번에 뽑기** — 두 칸이 같이 돌다가 왼쪽·오른쪽 차례로 멈춥니다
- **하나씩 뽑기** — 첫 번째, 두 번째를 따로 뽑습니다
- **예시 낱말** — 두 자음이 들어간 낱말을 뜻과 함께 3개씩 보여 줍니다.
  순우리말과 한글날 낱말을 먼저 보여 주고, 다시 누르면 다른 낱말로 바뀝니다
- 자음은 도트로 직접 그려서 글꼴이 없어도 늘 같은 모양으로 보입니다
- 흙·돌·나무 무늬와 인벤토리 칸은 그때그때 그려 냅니다. 그림 파일이 없습니다

## 어떻게 쓰나

주소를 열면 끝입니다. **인터넷도, 로그인도 필요 없습니다.**
바깥에 물어보는 곳이 한 군데도 없어서, `index.html` 파일 하나만
노트북에 복사해 두어도 그대로 돌아갑니다. 부스 인터넷이 끊겼을 때를
대비해 파일을 하나 받아 두면 마음이 편합니다.

- `Space` 뽑기 · `R` 초기화 · `F` 전체화면 · `H` 예시 낱말
- **같은 자음 중복 허용** — 꺼 두면 서로 다른 자음 두 개가 나옵니다
- **효과음** — 부스가 시끄러우면 끕니다

## 예시 낱말을 더 넣으려면

`index.html` 안의 `const WORDS = [` 목록에 한 줄을 더합니다.

```js
["도깨비", "뿔이 난 우리 옛이야기 속 귀신", "순우리말"],
```

갈래는 `한글날`, `순우리말`, `우리말`, `외래어` 넷입니다. 앞의 것부터
먼저 보여 줍니다.

두 자음이 **서로 다른 글자**에 들어 있어야 예시로 나옵니다.
`백성`이 ㅂ+ㄱ 예시에 안 나오는 까닭입니다. `백` 한 글자 안에서
ㅂ과 ㄱ이 이어지기 때문입니다.
